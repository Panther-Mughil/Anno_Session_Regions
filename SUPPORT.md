# Support

## Read first

- `docs/troubleshooting.md` lists the common symptoms and the approaches that do not work.
- `docs/faq.md` answers the usual questions.
- `docs/how_it_works.md` explains the mechanism.

## Ask a question or report a problem

Open an issue on GitHub:

- Use the bug report template for a problem.
- Use the feature request template for a change.
- For a region test result, open a bug report and say that it is a test report.

Include the game version, the host region, the custom session GUID, the generated config, and the loader log. A clear report with files is easier to act on.

## Security

Read `SECURITY.md` before posting details of a security problem in public.
